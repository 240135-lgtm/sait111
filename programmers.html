Великие Программисты

Архитекторы цифрового мира, создавшие технологии, которые изменили нашу жизнь и продолжают формировать будущее

Линус Торвальдс

1969 — наст. время

Финско-американский программист, создатель ядра Linux и системы контроля версий Git. Его проекты лежат в основе современной IT-инфраструктуры.

Linux Git Open Source

Алан Тьюринг

1912 — 1954

Британский математик, считающийся отцом информатики и искусственного интеллекта. Создал формальную концепцию вычислений (машина Тьюринга).

Машина Тьюринга Криптография Тест Тьюринга

Деннис Ритчи

1941 — 2011

Американский учёный в области компьютерных наук. Создатель языка программирования C и один из разработчиков операционной системы UNIX.

Язык C UNIX Bell Labs

Тим Бернерс-Ли

1955 — наст. время

Британский учёный, изобретатель Всемирной паутины (WWW). Создал первый веб-браузер и веб-сервер, заложив основу современного интернета.

World Wide Web HTML HTTP

Билл Гейтс

1955 — наст. время

Американский предприниматель, сооснователь Microsoft. Сделал персональные компьютеры доступными для миллионов людей по всему миру.

Microsoft Windows MS-DOS

Стив Джобс

1955 — 2011

Американский предприниматель, сооснователь Apple. Революционер в области персональных компьютеров, смартфонов и цифровой музыки.

Apple iPhone Mac

Ада Лавлейс

1815 — 1852

Английский математик, считается первым в истории программистом. Написала первую программу для аналитической машины Бэббиджа.

Первый программист Алгоритмы Математика

Гвидо ван Россум

1956 — наст. время

Голландский программист, создатель языка программирования Python. Его язык стал одним из самых популярных в мире благодаря простоте и универсальности.

Python BDFL ABC язык

Бьёрн Страуструп

1950 — наст. время

Датский программист, создатель языка программирования C++. Расширил язык C объектно-ориентированным программированием.

C++ ООП Bell Labs

Дональд Кнут

1938 — наст. время

Американский учёный в области информатики, автор «Искусства программирования». Создатель системы вёрстки TeX, используемой учёными по всему миру.

Искусство программирования TeX Алгоритмы
